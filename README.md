# VortexTech Cyber Security — Week 4

## Mini Incident Response Plan

This repository contains a structured Mini Incident Response Plan created for the Cyber Security Internship Track — Week 4.

The plan presents a realistic hypothetical cybersecurity breach involving a fictional online retail company. The scenario focuses on customer data exposure caused by an unsecured API endpoint.

The response plan follows the six phases of the NIST Incident Response Lifecycle:

1. Preparation
2. Detection and Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

The repository also includes:

* A realistic breach scenario
* Incident response actions for each phase
* An internal communication plan
* Preventative security measures
* Recommendations for reducing the risk of similar incidents

## Scenario Summary

A fictional online shopping company experienced a customer data exposure after an unsecured API endpoint allowed unauthorized access to customer information. The incident response plan explains how the company would detect, contain, investigate, remove, and recover from the breach.
